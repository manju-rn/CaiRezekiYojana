# Sample portfolio

`cairezeki-sample-portfolio.csv` is a ready-to-import portfolio worth about
**SGD 100,000**, in the single CSV format Settings > Import takes (the format's
columns are listed on that page, and `Download template` gives a blank one).

| Part | Share | Holdings |
|---|---|---|
| Singapore ETFs (SGX) | 15% | G3B (Amova Singapore STI ETF) about two-thirds, SRT (CSOP iEdge S-REIT Leaders ETF) one-third |
| UCITS ETFs (LSE, USD) | 50% | SWRD 30%, WSML 10%, IGLN 10% of the portfolio |
| Indian mutual funds (INR) | 10% | DSP Large Cap Fund (equity) 8%, DSP Money Market Fund (debt) 2% |
| Cash (SGD) | 25% | DBS Multiplier |

Quantities were worked out from the prices on 30 October 2026 (USD/SGD 1.2788,
SGD/INR 74.296), so the file totals SGD 100,000.00 on that day. Prices and
exchange rates are refreshed from the feeds after the import, so today's figures
move with the market. The UCITS split (60/20/20) and the Indian funds' 80/20
equity/debt split are choices made for the sample - change the Quantity column
to taste.

An import adds to what is held. To start again, delete the portfolio first
(Settings > Delete data) and import the file.
